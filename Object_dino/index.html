Abstract

Self-supervised Vision Transformers (ViTs) like DINO show an emergent ability to discover objects, typically observed in [CLS] token attention maps of the final layer. However, these maps often contain spurious activations resulting in poor localization of objects. This is because the [CLS] token, trained on an image-level objective, summarizes the entire image instead of focusing on objects. This aggregation dilutes the object-centric information existing in the local, patch-level interactions. We analyze this by computing inter-patch similarity using patch-level attention components (query, key, and value) across all layers. We find that: (1) Object-centric properties are encoded in the similarity maps derived from all three components (q, k, v), unlike prior work that uses only key features or the [CLS] token. (2) This object-centric information is distributed across the network, not just confined to the final layer. Based on these insights, we introduce Object-DINO, a training-free method that extracts this distributed object-centric information. Object-DINO clusters attention heads across all layers based on the similarities of their patches and automatically identifies the object-centric cluster corresponding to all objects. We demonstrate Object-DINO's effectiveness on two applications: enhancing unsupervised object discovery (+3.6 to +12.4 CorLoc gains) and mitigating object hallucination in Multimodal Large Language Models by providing visual grounding. Our results demonstrate that using this distributed object-centric information improves downstream tasks without additional training.

Motivation

DINO's training objective is global and image-level. Consequently, the [CLS] token must learn to encode holistic image cues rather than focus on precise object regions. This limitation motivates us to reconsider where object-centric information truly resides. For the global summary to capture semantic richness, the self-attention mechanism must establish correspondences between individual patches based on visual similarity. This suggests object-centric information is more directly accessible via local, patch-level groupings (query, key, and value matrices) rather than the noisy [CLS] token. Furthermore, our analysis reveals that this information isn't just trapped in the final layer—it is distributed throughout the network.

Object-DINO Method

We introduce Object-DINO, a training-free algorithm that identifies a distributed set of object-centric heads from a pre-trained model.

  • Phase 1: Feature Extraction. For every head across all layers, we compute the patch similarity maps from its query, key, and value representations. These three maps are ensembled and flattened to create a vector representing each head's localization pattern.
  • Phase 2: Head Clustering. All heads are clustered based on these patterns using k-means. Guided by the observation that object-centric info is prevalent in the final layer, we identify the "Object Cluster" as the one containing the highest prevalence of final-layer heads.
Aggregating the similarity maps from only these distributed object-centric heads produces a high-fidelity object localization, effectively filtering out noise.

Applications & Results

1. Unsupervised Object Discovery

We replace the baseline strategy in the TokenCut framework (which naively uses all final-layer key heads) with our automatically discovered set of distributed object-centric heads. This yields substantial CorLoc gains (+3.6 to +12.4) across PASCAL VOC and COCO benchmarks for both DINO-V2 and DINO-V3 without any training.

2. Mitigating MLLM Hallucinations

We apply Object-DINO to provide visual grounding for Multimodal Large Language Models (MLLMs). By amplifying visual evidence during generation—using an object map to highlight visually grounded regions—our training-free decoding strategy corrects hallucinations, achieving state-of-the-art precision and F1 scores on the POPE and CHAIR benchmarks.
